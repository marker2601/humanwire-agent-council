## What the benchmark changes

Six patterns repeat across the strongest products:

1. The first screen states an outcome, not a model capability.
2. Agents have named roles, bounded assignments, and visible handoffs.
3. The product shows live work and saved state rather than a single spinner.
4. Evidence, inference, and human authority are visually distinct.
5. Cross-channel action is useful only when consent, identity, and fallback are explicit.
6. The finished artifact is concrete: a brief, next action, owner, and audit trail.

HumanWire already satisfies the difficult architectural patterns: durable execution, bounded Gemini specialists, explicit authority, and saved replay. A wholesale redesign would reduce clarity and increase submission risk. The release revision is therefore deliberately focused:

- replace generic demo-stakeholder events with named, role-specific contributions;
- reveal the structured Agent Council recommendation automatically when a mission completes;
- keep the final state explicitly at **human approval required**;
- record a fresh release video from the current deployed DecisionOS product rather than reuse the earlier coordination-studio footage.

That is the strongest competition position: not “another agent builder,” but a decision-control plane that lets agents do the coordination while preserving evidence and human authority.
